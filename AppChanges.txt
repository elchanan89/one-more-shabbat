7. Add Reset Selection Option for Parent Mode
In the Shabbat selection popup, when the card is in Parents mode, add a red Reset Selection button.

Requirements
The button should be visually distinct and styled as a destructive action (red color).
When clicked, the user should be prompted for confirmation before the action is executed.
Upon confirmation:
The current selection for that Shabbat is cleared.
The stored shabbatOptions value is reset to its unselected state.
The corresponding Shabbat card returns to the original unselected/disabled (grayed-out) appearance.
The card should behave exactly as a newly created Shabbat that has not yet been assigned an option.
The reset action should immediately update the UI and persist the change in storage/backend.
The reset functionality should only be available when the Shabbat currently has a selection assigned.
